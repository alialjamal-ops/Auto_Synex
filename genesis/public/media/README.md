# Demo media

- `clinic/`, `salon/`, `academy/`, `studio/`, `team/`: photography from
  [StockSnap.io](https://stocksnap.io) (CC0 public domain), the same set the
  repository's `demos/` app uses. Resized and converted to WebP. Team photos
  are crops of those images and depict models, not real staff.
- `product/`: screenshots of this Genesis demo itself (sample data only).
